\section{Introduction}
ZameenLink is a comprehensive real estate analytics platform designed to predict property prices in Bhopal using advanced Machine Learning algorithms. As the Team Leader and Lead Architect, I was responsible for the core vision, system design, and the implementation of the most critical back-end logic, including the ML pipeline and the scam detection engine.

\section{Core Responsibilities}
My primary responsibilities within the team included:
\begin{itemize}
    \item \textbf{Project Leadership:} Dividing modules, setting timelines, and ensuring code quality.
    \item \textbf{System Architecture:} Designing the interactions between the Flask backend and React frontend.
    \item \textbf{Machine Learning:} Developing the training pipeline to compare Linear Regression, Random Forest, and XGBoost.
    \item \textbf{Algorithm Design:} Creating the Scam Detection Logic and Feature Engineering (Geospatial calculations).
\end{itemize}

\section{Detailed Technical Contribution}

\subsection{Machine Learning Pipeline (\texttt{train\_model.py})}
I architected the entire training pipeline which automates the lifecycle of model creation:
\begin{itemize}
    \item Implemented a comparative analysis system that trains three distinct models simultaneously.
    \item Added logic to automatically save the best-performing model based on $R^2$ Score.
    \item Logic Example:
    \begin{lstlisting}[language=Python]
models = {
    'Linear Regression': LinearRegression(),
    'Random Forest': RandomForestRegressor(n_estimators=100),
    'XGBoost': XGBRegressor(n_estimators=100)
}
# ... training loop ...
best_model = max(results.items(), key=lambda x: x[1]['r2_score'])
    \end{lstlisting}
\end{itemize}

\subsection{Scam Detection Algorithm (\texttt{scam\_detector.py})}
One of the unique features I implemented was the logic to flag potential scams. This was not just a simple threshold but a deviation metrics calculator:
\begin{itemize}
    \item The system calculates the percentage difference between the \textit{Listed Price} and the \textit{Predicted Fair Value}.
    \item Defined risk categories:
    \begin{itemize}
        \item \textbf{CRITICAL (>30\% deviation):} High probability of fraud.
        \item \textbf{medium (10-20\%):} Overpriced but common.
        \item \textbf{BARGAIN (<-5\%):} Undervalued properties.
    \end{itemize}
\end{itemize}

\subsection{Feature Engineering (\texttt{feature\_engineering.py})}
I developed the geospatial logic to calculate distances from key Bhopal landmarks (DB Mall, AIIMS, Airport) using the \texttt{geopy} library. This was crucial for improving model accuracy as location is the primary driver of real estate value.

\section{Challenges \& Solutions}
\textbf{Challenge:} The models were initially overfitting on the synthetic data.\\
\textbf{Solution:} I tuned the hyperparameters for XGBoost (max\_depth=7) and Random Forest (max\_depth=15) to generalize better.

\section{Conclusion}
My contribution laid the technical foundation for ZameenLink. By establishing a robust ML pipeline and a unique scam detection feature, I ensured the project met its primary academic and functional goals.
