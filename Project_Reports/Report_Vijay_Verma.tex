\section{Introduction}
Machine Learning models are only as good as the data they are trained on, and insights are only useful if they are visualized clearly. My role in ZameenLink was bridging the gap between raw data and visual understanding. I was responsible for generating the realistic dataset for Bhopal and creating the visual analytic tools in the frontend.

\section{Core Responsibilities}
\begin{itemize}
    \item \textbf{Data Generation:} Creating highly realistic synthetic property data for Bhopal.
    \item \textbf{Data Visualization:} Implementing charts (Bar, Pie) using Recharts.
    \item \textbf{Heatmap Logic:} Developing the visual density layers for property prices.
    \item \textbf{Comparison Tools:} Building the logic to compare different ML models side-by-side.
\end{itemize}

\section{Detailed Technical Contribution}

\subsection{Data Generator (\texttt{data\_generator.py})}
Since real-time API access to real estate data is expensive/restricted, I built a sophisticated script to generate 300+ realistic property listings.
\begin{itemize}
    \item Mapped real areas in Bhopal (e.g., Arera Colony, MP Nagar).
    \item Assigned base prices per square foot for each zone to ensure realism.
    \item Added random variance to simulate market fluctuations.
    \item Result: A robust CSV dataset that allows our ML models to train effectively.
\end{itemize}

\subsection{Analytics Dashboard (\texttt{Analytics.jsx})}
I integrated the \texttt{recharts} library to provide users with deep insights:
\begin{itemize}
    \item \textbf{Model Accuracy Chart:} A bar chart comparing RMSE and MAE across our three models.
    \item \textbf{Price Distribution:} Visualizing the spread of property prices in the current view.
\end{itemize}

\subsection{Heatmap Visualization (\texttt{PriceHeatmap.jsx})}
I implemented the Heatmap layer using Leaflet:
\begin{itemize}
    \item This visualizes high-value zones in Red and low-value zones in Blue/Green.
    \item It processes the lat/long and price intensity of all properties to generate a seamless gradient overlay on the map.
\end{itemize}

\section{Challenges \& Solutions}
\textbf{Challenge:} The generated data initially lacked geographic consistency (e.g., cheap properties in expensive zones).\\
\textbf{Solution:} I implemented a "Zone Multiplier" logic in the generator script that enforces a base price floor for premium areas like Arera Colony.

\section{Conclusion}
My work ensured that ZameenLink was not just a functional app but an analytical tool. The data generation pipeline enabled the project to proceed without external dependencies, and the visualizations provide the primary value-add for the end user.
